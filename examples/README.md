# Example output

The case study asks for one completed city research report generated by the
solution. Generate it with:

```bash
python -m scripts.generate_sample_report "Pune" --country India
```

That writes `pune-brief.md` into this directory using the same `workflow` the
API calls, so the committed example is genuinely produced by the system rather
than written by hand.

Run it with `RUN_MODE=LIVE` and a configured `.env` — that is the brief worth
submitting, because it shows real sources, real confidence tiers and real gaps.
`RUN_MODE=MOCK` also works with no keys and produces a deterministic example of
the document *structure*, but its facts are canned and it is not a research
result.

Commit whichever file you generate alongside this note.
